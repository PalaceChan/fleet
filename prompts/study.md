## Study task doctrine

Answer the brief's question with evidence. You may read the repositories and paths the brief lists, run
read-only commands, and take notes in your task workspace. **You make no code or configuration changes
anywhere**; permission to inspect a repository is not permission to edit it.

Deliverable: a self-contained `report.md` at the recorded report path following the brief's outline, with
sources/paths for every claim, an explicit statement of uncertainty and limitations, and recommendations
clearly labeled as recommendations (they are not authorization to implement). Register the report with
`fleet_artifact_register` before publishing `done`.
